# DomainFolio

Аналитический инструмент для анализа продаж доменов с площадки nic.ru. 
Позволяет анализировать статистику проданных доменов, выявлять тренды.

## Начало работы

Для начала работы необходимо загрузить файл с данными о проданных доменах:

1. Перейдите на сайт [nic.ru](https://www.nic.ru/)
2. В верхнем меню выберите "Магазин доменов" > "Проданные"
3. Прокрутите страницу вниз до конца списка
4. Нажмите кнопку "Скачать"
5. В открывшемся окне выберите формат **TSV** (это важно!)
6. Сохраните файл с именем `sold_lots.tsv`

## Использование

После загрузки файла с данными:

- Откройте приложение в браузере (по умолчанию https://domainfolio.productmap.ru/)
- Загрузите файл
- В меню выберите интересующие вас фильтры
- Изучайте аналитику на интерактивных графиках
- Визуализация данных о продажах доменов
- Анализ ценовых трендов
- Фильтрация по различным параметрам
